
# AURA - Personal Voice Assistant

AURA is a Python-based voice-controlled desktop assistant.

## Features
- Speech recognition
- Text-to-speech responses
- Voice-controlled website navigation
- Date and time information
- Google search using voice commands

## Technologies
- Python 3.13
- SpeechRecognition
- PyAudio
- pyttsx3

## Installation

Clone the repository and navigate to this folder.

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the assistant:

```bash
python aura.py
```
